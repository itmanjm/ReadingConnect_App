# Hard Prompts Layer

> Reusable instruction templates for LLM sub-tasks.
> These are fixed instructions, not context or goals.

## Available Prompt Templates

- **[summarize.md](summarize.md)** - Transcript → summary workflow (key points, action items, questions)
- **[outline.md](outline.md)** - Topic → outline workflow (structure, sections, resources)
- **[rewrite.md](rewrite.md)** - Content in voice workflow (voice/style adjustments, quality checks)
- **[research.md](research.md)** - Research workflow prompts (multi-source investigation, evidence-based findings)

## Usage

These prompts provide:
- Structured instructions for common workflows
- Voice and style guidelines
- Output formats and quality standards
- Best practices and anti-patterns

Use them when:
- Summarizing meetings, transcripts, or long content
- Creating outlines from topics or notes
- Rewriting content for specific audiences
- Conducting research or investigations
