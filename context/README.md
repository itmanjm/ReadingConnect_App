# Context Layer

> Domain knowledge, reference material, and style guides.
> This layer shapes quality and style — not process or behavior.

## Available Context Files

- **[icp.md](icp.md)** - Ideal Customer Profile descriptions (user identity, values, work style)
- **[voice.md](voice.md)** - Writing tone and style guide (communication patterns, anti-patterns)

## Examples Directory

- **[examples/positive.md](examples/positive.md)** - Good output examples to use as quality benchmarks
- **[examples/negative.md](examples/negative.md)** - Anti-patterns to avoid

## Usage

Add context files to share knowledge about:
- User preferences and values
- Domain expertise areas
- Writing samples and style guides
- Positive and negative examples for reference
